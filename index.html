Two-Stage LLM Classifier & Query Router

The Problem

High latency and prohibitive API costs when passing raw user prompts directly to heavy LLMs without context evaluation.

The Approach

Engineered a lightweight intent classifier stage to parse vector embeddings and route standard queries to cached micro-models while dispatching complex queries to LLMs.

The Impact

Reduced median API latency by 42% and decreased compute token consumption while maintaining 99.4% classification accuracy.
